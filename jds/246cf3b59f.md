We are seeking a highly technical Application Engineer with strong expertise in automation to design, evaluate, and implement scalable automation solutions across enterprise systems. * Among other tasks, this role is responsible for creating, reviewing, and validating Process Design Documents (PDDs) to ensure they are complete, technically accurate, and suitable for automation. * The engineer will assess processes for automation feasibility, identify gaps, edge cases, exception scenarios, and system dependencies, and guide teams in developing high-quality, automation-ready PDDs. * The engineer will translate process requirements into technical workflows, build and deploy automations, integrate APIs and external systems, and ensure solutions are reliable, maintainable, and production-ready. * This role requires strong analytical skills, hands-on automation development experience, and the ability to define and enforce best practices for automation design and documentation. Tools & Technologies: * The candidate must have hands-on experience with enterprise automation platforms such as UiPath, Blue Prism (BP), Quick Automate, or similar workflow automation tools, including designing workflows, managing orchestration, implementing exception handling, and deploying and monitoring automations in production environments. * Strong proficiency in Python is required for developing custom automation scripts, integrating with REST APIs, processing and transforming data, and extending automation capabilities beyond native platform features. * Experience using Python libraries such as requests or httpx for API integrations, pandas for data handling, and logging frameworks for debugging and monitoring is essential. * The candidate should also be familiar with REST APIs, JSON, webhooks, Git for version control, Postman for API testing, and basic SQL for validating data and supporting automation testing and evaluation
